| Future Google CMP/ads | Consent strings, vendor choices, advertising/network identifiers according to actual setup | NOT ACTIVE; Google/actual selected vendors only after approval | Provider configuration not yet known | Region/purpose-specific consent and justified processing; later active-vendor disclosure and revocation |
| Playgama | None currently | Inquiry document only, no SDK/client ID | N/A current visitor flow | Provider consent/roles/exclusivity unknown; do not activate |

The main document hosts the game canvas inside a same-origin iframe with allow=autoplay and no sandbox attribute. Existing bridge validates origin, source frame, protocol version and game/request scope. Future H5 must execute in the game document; Google CMP must execute in the top-level document. Consent propagation and callback mapping are later approved integration requirements, not established by placing a tag only in the portal.

Rights: local saves are not available to the operator remotely; users control origin storage. Contact/log-related rights require a working email channel and provider process. Applicable GDPR rights and CPDP complaint route must be explained in the approved privacy notice. Do not promise absolute erasure of provider security logs, fixed retention, worldwide compliance or a nonexistent DPO.
