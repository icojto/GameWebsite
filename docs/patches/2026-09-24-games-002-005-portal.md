# Portal Games 002-005 integration - 2026-09-24

## Scope

Integrated the four existing local games into the portal without modifying their original repositories:

- Game 002: Reactor Stack (`games/reactor-stack`)
- Game 003: Last Relay (`games/last-relay`)
- Game 004: Station Quartermaster (`games/station-quartermaster`)
- Game 005: Signal Below (`games/signal-below`)

Each catalog entry has a dedicated `/games/<slug>` route and an isolated same-origin iframe. The homepage creates cards only; an embedded game is created only when its game page opens.

## Integration details

- The catalog-driven build and check scripts now process all five games using the portal root's Vite, Phaser, TypeScript, and Node typings.
- Vite is invoked with the per-game nested base `/games/<slug>/embed/`, so generated assets resolve from each iframe path.
- Reactor Stack keeps its drag/tap board input and session sound preference.
- Last Relay retains its landscape-first lane-defense controls and no-sound v0.1 scope.
- Station Quartermaster keeps browser-local scenario saves.
- Signal Below retains its authored procedural SVG scene assets and browser-local checkpoints.

## Deliberate exclusions

No original game project was edited. No generated portal output, dependencies, secrets, accounts, ads, payments, cloud saves, analytics, backend, deployment, or monetization was added.
