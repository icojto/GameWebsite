# Signal Below

A small, complete atmospheric sci-fi mystery. You are an unnamed maintenance technician sent to an empty communications relay. Its incoming channel is already open, and every measurement says the source is beneath the station.

## Run

```powershell
npm.cmd install
npm.cmd run dev
```

Open the address printed by Vite. Click or tap the illuminated scene markers; on narrow portrait screens the same controls appear below the scene. A valid user gesture enables the optional synthesized ambience.

## Controls and defaults

- Four fixed locations are unlocked by their completed investigation, rather than application-level room states.
- The eight non-final responses set only five explicit flags: `asked_identity`, `asked_below`, `challenged_signal`, `trusted_signal`, and `rejected_signal`.
- Three clues are stored once and all are required for the final decision.
- The final lower relay offers two endings: **Silence** (seal the station) and **Answer** (bridge the lower path).
- Responsive presentation uses a 16:9 procedural scene canvas. Mobile landscape displays the interaction list beside the scene; portrait puts it below, preserving large tap targets.

## Checkpoints

Checkpoints use browser `localStorage` under `hristo.signal-below.checkpoint`. The payload carries schema version `1`, game ID `signal-below-005`, ISO timestamp, and only stable logical state. It saves after each interaction, meaningful choice, clue, and room entry. Corrupt data, an unknown schema/game ID, dangling content references, and inconsistent state are rejected without replacement.

## Development commands

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

Scene source is generated by `scripts/generate-art.mjs` into `public/art/`. Each SVG is an intentional asset-swap point and can be replaced by another `1440 × 810` composition without touching narrative logic.
